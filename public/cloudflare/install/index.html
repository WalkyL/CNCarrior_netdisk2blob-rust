安装 catalog

页面从静态 JSON 渲染，便于后续替换包管理器、镜像源和平台 profile。

PVE LXC / Linux

推荐宿主：下载 `ccbg-lxc-package.tar.gz`，先用 `tar --no-same-owner -xzf` 解包。`scripts/install.sh --s3-only` 只启用 S3 gateway；`scripts/install.sh --enable-smb-sidecar` 会额外安装 rclone/samba/fuse3、启用 sidecar units，并在 Admin 中打开 SMB。

SMB sidecar profile

如果安装时选择 SMB sidecar，安装脚本会先启动 CCBG 管理的 `smbd` 并监听 `0.0.0.0:445`。第一次使用时，进 Admin 添加一个 SMB 用户就会自动生成 `CCBGRoot` 默认共享；真实挂载这个共享时，PVE/LXC guest 还需要暴露 `/dev/fuse` 给 rclone mount。

Windows / macOS

Windows 使用包内 PowerShell 安装脚本；macOS 使用包内 launchd 安装脚本。官方宿主包默认把 Admin Web 打开到 `0.0.0.0:61081`。
