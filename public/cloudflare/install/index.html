安装与下载入口

安装路径优先级：LXC/Linux 稳定优先；fnOS 为 NAS/Linux 实验宿主；OpenWrt 保留实验支持。

LXC / Linux（推荐）

包名：ccbg-lxc-package.tar.gz

SHA256：构建后见 target/lxc-package/ccbg-lxc-package.tar.gz.sha256

build-lxc-package.sh

install.sh

fnOS（实验，优先于 OpenWrt）

定位：NAS/Linux 实验宿主，优先 Docker/Compose 路径。

风险：不承诺应用商店上架，不承诺零配置。

参考 Linux/LXC 部署与 smoke

OpenWrt（实验）

包名：ccbg-openwrt-lite.tar.gz

SHA256：构建后见 target/openwrt-lite/ccbg-openwrt-lite.tar.gz.sha256

支持线：64MB 仅实验；128MB 可测；256MB+ 推荐

build-openwrt-lite-package.sh

install.sh
