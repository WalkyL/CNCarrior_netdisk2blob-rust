Install first

选择平台，一条命令启动本地网关

macOS 使用 `launchd`，Windows 使用无额外依赖的后台常驻任务路径； Linux 优先 LXC、Docker 和 Podman。

查看命令 GitHub Releases
macOS Release package 
curl -fsSLO https://github.com/WalkyL/CNCarrior_netdisk2blob-rust/releases/latest/download/ccbg-macos-arm64.tar.gz
tar -xzf ccbg-macos-arm64.tar.gz
./ccbg-macos-arm64/deploy/macos/install.sh
Windows PowerShell 
Invoke-WebRequest https://github.com/WalkyL/CNCarrior_netdisk2blob-rust/releases/latest/download/ccbg-windows-x86_64.zip -OutFile ccbg-windows-x86_64.zip
Expand-Archive -Force ccbg-windows-x86_64.zip -DestinationPath .\ccbg-release
.\ccbg-release\ccbg-windows-x86_64\deploy\windows\install.ps1
