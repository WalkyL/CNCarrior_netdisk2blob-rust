Install first

选择平台，一条命令启动本地网关

macOS 使用 `launchd`，Windows 使用无额外依赖的后台常驻任务路径； Linux 优先 LXC、Docker 和 Podman。

查看命令 GitHub Releases
macOS Homebrew 
brew install walky/tap/carrier-cloud-blob-gateway
brew services start carrier-cloud-blob-gateway
Windows PowerShell 
Invoke-WebRequest https://github.com/walky/carrier-cloud-blob-gateway/releases/latest/download/ccbg-windows-x86_64.zip -OutFile ccbg-windows-x86_64.zip
Expand-Archive -Force ccbg-windows-x86_64.zip -DestinationPath .\ccbg-release
.\ccbg-release\ccbg-windows-x86_64\deploy\windows\install.ps1

PVE LXC / Linux

推荐宿主：下载 `ccbg-lxc-package.tar.gz`，执行包内 `scripts/install.sh`。

Windows / macOS

Windows 使用 winget 或包内 PowerShell 安装脚本；macOS 使用 Homebrew 或包内 launchd 安装脚本。
