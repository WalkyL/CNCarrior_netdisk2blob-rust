FAQ 目录与匹配 API

FAQ catalog 是结构化 JSON；匹配使用关键词/provider/context/config_key/error_pattern 加权评分，不使用向量库。

Catalog

GET /api/faq/catalog

打开 catalog

Match API

POST /api/faq/match，输入 query/provider/context/config_keys/limit。

curl -sS -X POST /api/faq/match \
  -H 'content-type: application/json' \
  -d '{"query":"mobile token expired","provider":"mobile","context":"logs","limit":3}'
