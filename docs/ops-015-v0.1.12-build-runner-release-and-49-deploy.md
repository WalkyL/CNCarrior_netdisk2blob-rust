## `.49` Deploy

Target:

- host: `root@192.168.1.49`
- hostname: `ccbg01`

Deploy commands:

```bash
scp target/release-local/v0.1.12/ccbg-lxc-package.tar.gz root@192.168.1.49:/tmp/ccbg-lxc-package-v0.1.12.tar.gz
ssh root@192.168.1.49
rm -rf /tmp/ccbg-lxc-package-v0.1.12
mkdir -p /tmp/ccbg-lxc-package-v0.1.12
cd /tmp/ccbg-lxc-package-v0.1.12
tar --no-same-owner -xzf /tmp/ccbg-lxc-package-v0.1.12.tar.gz
cd ccbg-lxc-package
./scripts/install.sh --enable-smb-sidecar
```

## Release Tooling Fixes Confirmed During This Rollout

- the build-runner workflow must pass container proxy env as `http://192.168.1.52:10808`, not loopback
- macOS workflow inputs should stay disabled until the image really has a Darwin SDK-capable toolchain
- `scripts/download-build-runner-release-assets.sh` must handle:
  - artifact zip contents extracted directly under the destination root
  - artifact zip contents nested one directory deep
  - Windows `gh.exe` path expectations when invoked from Bash
- `scripts/release-local.sh` must convert absolute artifact paths when it ends up invoking a Windows `python.exe` from WSL
